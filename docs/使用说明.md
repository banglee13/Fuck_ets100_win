# 使用说明

## 安装步骤

### 方法一：使用启动脚本（推荐）

1. 双击运行 `启动.bat`
2. 脚本会自动完成以下操作：
   - 检查 Python 环境
   - 创建虚拟环境
   - 安装依赖
   - 启动程序

### 方法二：手动安装

1. **安装 Python**
   - 下载并安装 Python 3.8 或更高版本：https://www.python.org/downloads/
   - 安装时勾选 "Add Python to PATH"

2. **安装依赖**
   ```bash
   cd Fuck_ets_win
   pip install -r requirements.txt
   ```

3. **运行程序**
   ```bash
   python main.py
   ```

## 使用流程

### 1. 登录

- 启动程序后，会弹出登录对话框
- 输入 ETS100 手机号和密码
- 勾选"记住密码"可以方便下次登录
- 点击"登录"按钮

### 2. 获取作业列表

- 登录成功后，自动获取作业列表
- 也可以点击工具栏的"刷新作业"按钮手动刷新
- 左侧会显示所有作业

### 3. 查看答案

- 在左侧点击要查看的作业
- 程序会自动下载并解析
- 右侧会显示答案详情

### 4. 导出答案

- 选择已解析的作业
- 点击工具栏的"导出答案"
- 选择保存位置和文件名
- 答案会保存为文本文件

## 常见问题

### Q: 登录失败怎么办？

A: 
- 确认手机号和密码正确
- 检查网络连接
- 尝试在官方客户端登录，确认账号正常

### Q: 下载作业很慢？

A: 
- 这取决于网络状况
- 可以尝试更换网络环境
- 已下载的作业会缓存，下次查看不需要重新下载

### Q: 答案显示不完整？

A: 
- 尝试重新点击该作业，重新下载解析
- 检查官方客户端是否有该作业的完整内容

### Q: 会被官方检测到吗？

A: 
- 本工具使用和官方客户端相同的 API
- 建议不要频繁使用，避免账号异常
- 仅供学习交流使用

## 缓存目录

程序会在以下位置保存缓存：
- 配置文件：`C:\Users\你的用户名\.fuck_ets100\`
- 作业缓存：项目目录下的 `cache\` 文件夹

点击工具栏的"打开缓存目录"可以快速访问。

## 安全提示

1. 不要在公共电脑上使用
2. 不要泄露账号密码
3. 定期清理缓存和配置文件
4. 仅用于学习交流，不要用于作弊
